# Reste à travailler – PWA v2

Nouveauté : bouton **Actualiser** qui récupère l’heure actuelle du PC et recalcule immédiatement l’heure de fin.

## Test local
Servez ce dossier via localhost (par exemple `python -m http.server 8080`) et ouvrez `http://localhost:8080` dans Edge.

## Installation PWA
Pour une installation normale, publiez les fichiers sur un hébergement HTTPS, ouvrez l’adresse dans Edge puis choisissez l’installation de l’application.
